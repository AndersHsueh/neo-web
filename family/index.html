家族关系

对外品牌和命令都叫 neo。源码仓库是 neo-cli；亦称 neo-agent。下面按「现在能用」和「还不是」分开说明。

现在能用

现在能用

  • neo（仓库 neo-cli） 目前能对外认真讲的产品。在本地终端里工作，以 GitHub 源码提供，用 Bun 运行。当前已发布版本 v0.4.99。在 GitHub 查看 neo-cli。
还不是

还不是

  • neo-agent-app GitHub 上有这个仓库，偏本地联调与演示，不是已交付的桌面产品。AndersHsueh/neo-agent-app
  • neo-core-serve 版本 0.0.2，未追平 neo-cli。2026-11-19 起已搁置。运行时住在 core-serve 是规划，不是现状。AndersHsueh/neo-core-serve
  • neo-agent-ios 空壳。仓库 README 写明：业务代码未开始。AndersHsueh/neo-agent-ios
  • 没有这些 没有 neo-agent-android，没有可用的 neo-bot，也没有独立的 neo-HomePage 仓库。
