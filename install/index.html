安装 · 当前版本 v0.4.99

从源码安装

neo 以 GitHub 源码提供，用 Bun 运行。下面的步骤对应当前已发布的 v0.4.99，命令来自仓库 README 与发版时的安装流程。

neo is provided as source on GitHub and runs with Bun. The steps below follow the current published tag, v0.4.99, using commands from the repository README and the release install path.

  1. 安装 Bun

    需要 Bun 1.1 或更高版本（package.json 中的 engines.bun 为 >=1.1.0）。仓库 README 写明实测过 1.3.13。

    Install Bun 1.1 or newer. The README records 1.3.13 as a version that has been used in practice. See bun.sh for the official installer.

    官方安装说明见 bun.sh。

  2. 克隆源码并检出已发布版本

    源码只从 GitHub 获取。先克隆 neo-cli，再检出当前已发布的标签，避免默认分支上尚未发版的改动。

    Clone the repository from GitHub, then check out the current published tag so you are not on unreleased commits from the default branch.

    git clone https://github.com/AndersHsueh/neo-cli.git
cd neo-cli
git checkout v0.4.99

  3. 安装依赖

    全新工作树需要先安装依赖。这是仓库发版说明里对全新工作树使用的命令：

    A fresh working tree needs dependencies installed first. This is the command the release notes use for a fresh working tree:

    bun install --frozen-lockfile

  4. 启动

    在仓库根目录运行：

    From the repository root:

    bun run src/index.ts

    Linux 和 macOS 也可以用 ./neo.sh。Windows 使用 neo.cmd（需要 Bun 已在 PATH 中）；Windows 支持目前是实验性的，仓库说明为尚未实机验证。

    On Linux and macOS you may also run ./neo.sh. On Windows use neo.cmd (Bun must be on your PATH). Windows support is experimental and, per the repository, has not been verified on a real machine.

  5. 配置

    交互式 TTY 下，如果候选路径里还没有任何 settings.json，首次启动会进入配置向导，成功后写入 ~/.neo/settings.json。也可以先自行复制并编辑示例配置再启动：

    On an interactive TTY, if no settings.json is found in the candidate paths, the first launch starts a setup wizard and can write ~/.neo/settings.json. You can also copy and edit the example file before launching:

    cp settings.example.json settings.json

    可选体检（只读报告，不进入界面、不发模型请求）：

    Optional read-only configuration check (it does not enter the UI or send model requests):

    bun run src/index.ts doctor

许可与获取方式

源码许可是木兰宽松许可证，第 2 版。同时，package.json 里仍是 "private": true，因此它不是 npm 包，也不能从任何 registry 安装。请只从 GitHub 上的 neo-cli 获取源码。

The license is Mulan Permissive Software License, Version 2. The package is still marked "private": true in package.json, so it is not an npm package and cannot be installed from a registry. Get the source only from neo-cli on GitHub.

源码在 GitHub：AndersHsueh/neo-cli。许可：木兰宽松许可证，第 2 版。当前已发布版本 v0.4.99。
