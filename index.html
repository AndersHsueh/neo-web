neo

neo 是一个在本地终端里工作的编程 Agent，目前以 GitHub 源码提供，用 Bun 运行。这个站点是它的官方入口，如实说明现在能用的东西。

neo is a coding agent that works in your local terminal. It is provided as source on GitHub and runs with Bun. This site is the official entry point, and it describes what you can use today.

它在本地仓库里读改代码、跑命令，走的是终端里的 agent，不是云 IDE，也还不是桌面或移动产品。能力骨架在，界面和交付仍在打磨。

It reads and changes code in a local repository and runs commands there. It is a terminal agent, not a cloud IDE, and not a desktop or mobile product yet. The core is in place; the interface and packaging are still being refined.

现在能讲清楚的边界

  • 目前能对外认真讲的，是源码形态的 neo。仓库名是 neo-cli。
  • 需要自行克隆源码，用 Bun 运行。它还不是 npm 包，也不能从任何 registry 安装。
  • 桌面端和移动端都还不是已交付的产品。
